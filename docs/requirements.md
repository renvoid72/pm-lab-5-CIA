# Требования к продукту


## Пользователи и их задачи

| Пользователь | Что хочет сделать | Зачем |
|---|---|---|
| Аналитик дорожной безопасности | Быстро получать сводку по очагам аварийности | Готовить обоснованные отчёты для руководства |
| Инженер-проектировщик | Видеть конкретные адреса опасных участков | Планировать ремонт и обосновывать приоритеты |
| Сотрудник ГИБДД | Анализировать факторы риска на карте | Расставлять посты и камеры в нужных местах |

## Функциональные требования

| ID | Требование | Источник | Эпик | Приоритет (MoSCoW) |
|---|---|---|---|---|
| FR-01 | Система должна отображать на интерактивной карте опасные участки дорог | Устав, цель 1 | E3 (Карта) | Must |
| FR-02 | Система должна выявлять очаги аварийности по совокупности факторов (погода, время, дорога) | Бизнес-кейс | E2 (Аналитика) | Must |
| FR-03 | Система должна позволять фильтровать данные на карте по факторам риска | Устав, цель 2 | E4 (Фильтры) | Must |
| FR-04 | Система должна формировать отчёты с приоритетным списком участков для ремонта | Устав, цель 4 | E5 (Отчёты) | Should |
| FR-05 | Система должна выгружать сформированные отчёты в формате CSV | Интервью с заказчиком | E5 (Отчёты) | Could |

## Нефункциональные требования

| ID | Категория | Требование (измеримо) | Как проверим |
|---|---|---|---|
| NFR-01 | Производительность | Карта должна загружаться быстрее чем за 3 секунды на мобильном интернете | Замер скорости через Lighthouse (режим Slow 4G) |
| NFR-02 | Удобство использования | Интерфейс должен корректно работать на экранах шириной от 360 px, элементы управления доступны без зума | Проверка в режиме эмуляции мобильного устройства в браузере |
| NFR-03 | Совместимость | Корректное отображение и работа в последних версиях Chrome, Firefox, Safari | Кросс-браузерное тестирование |
| NFR-04 | Воспроизводимость | Весь процесс запуска прототипа с нуля должен занимать не более 15 минут по инструкции | Проверка другим участником команды по README |

## Требования к данным

| ID | Требование | Порог | Как проверим |
|---|---|---|---|
| DR-01 | Полнота | Данные о ДТП должны покрывать не менее 80% от официального перечня за 3 года | Сравнение с выборочными данными ГИБДД |
| DR-02 | Точность положения | Погрешность координат не более 50 метров для однозначной привязки к дороге | Выборочная проверка 30 случайных точек на карте |
| DR-03 | Актуальность | Данные загружены не раньше чем за 1 месяц до расчёта, периоды ДТП и погоды совпадают | Проверка через лог-файл загрузки данных |
| DR-04 | Лицензия и указание авторства | Используются только открытые данные, на карте всегда видна подпись «© OpenStreetMap» | Визуальная проверка интерфейса |

## Вне рамок продукта

- Автоматическая рассылка предписаний или штрафов.
