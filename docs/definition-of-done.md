# Definition of Ready и Definition of Done

## Definition of Ready (задача готова к работе)

Задачу можно брать в спринт, если:
- [ ] У неё есть понятная цель и критерии приёмки.
- [ ] Она привязана к эпику, у неё есть приоритет MoSCoW.
- [ ] Известно, какие данные нужны и где они лежат.
- [ ] Задача помещается в один спринт.
- [ ] Зависимости сняты или известно, когда они будут сняты.

## Definition of Done (задача выполнена)

### Для любой задачи
- [ ] Выполнены все критерии приёмки из задачи.
- [ ] Изменения влиты в `main` через PR с одобрением другого участника.
- [ ] Автопроверки в PR прошли без ошибок.
- [ ] Обновлена документация, если поведение изменилось.

### Для задач с данными
- [ ] Источник и дата загрузки записаны в реестре.
- [ ] Сырые данные не попали в Git.
- [ ] Расчёт выполнен в метрической системе координат (метры).
- [ ] Ноутбук запускается сверху вниз без ошибок.

### Для пользовательских историй
- [ ] История проверена по INVEST (независимая, обсуждаемая, ценная, оцениваемая, небольшая, проверяемая).
- [ ] В историях корректно указан приоритет MoSCoW.
