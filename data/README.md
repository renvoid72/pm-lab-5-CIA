# Данные проекта

Здесь лежат данные, с которыми работает проект. Реестр источников с описанием и оценкой каждого набора: [sources.md](sources.md).

## Структура

| Папка | Что лежит | В репозитории? |
|---|---|---|
| `raw/` | Данные в том виде, в каком их скачали. Не редактируем вручную. | Нет, только `.gitkeep`. Их можно скачать заново |
| `manual/` | Небольшие таблицы, собранные вручную из публикаций (например, население по районам). У каждой строки — год и ссылка на источник | Да |
| `processed/` | Очищенные данные, готовые для анализа (результат ноутбука 02) | Да, если файл меньше 10 МБ |
| `sources.md` | Реестр источников данных | Да |

Почему сырые данные не хранятся в Git: они большие, быстро устаревают и всегда восстанавливаются из источника. Зато способ их получения должен быть описан так, чтобы любой участник группы мог его повторить.

## Как получить данные

Данные хранятся в папке группы на Google Диске: `pm-lab-5-CIA` (владелец: Ковальчук В.).

1. Получите доступ к папке группы и добавьте ярлык на неё в «Мой диск» (приложение Б к ЛР 2, шаг 2).
2. Проверьте, что в папке на Диске есть `data/manual/` с теми же таблицами, что в репозитории.
3. Откройте `notebooks/01_data_collection.ipynb` в Google Colab, впишите имя папки в `PROJECT_FOLDER` и выберите **Среда выполнения → Выполнить все**. Ноутбук скачает дорожную сеть, светофоры и лежачие полицейские из OpenStreetMap в `data/raw/` на Диске и запишет дату загрузки в `data/raw/_download_log.json`.
4. При локальной работе вместо пунктов 1–3: `pip install -r requirements.txt` и запуск того же ноутбука из папки `notebooks/`. Файлы появятся в `data/raw/` репозитория.
5. **Данные ГИБДД (ДТП):** из корня репозитория выполните `python scripts/fetch_gibdd.py` (нужен пакет `requests`). Скрипт скачивает со stat.gibdd.ru ДТП по Уфе за 10.2023–09.2026 и сохраняет `data/raw/accidents.csv`; на Диск положите файл вручную в `data/raw/`. Пробный запуск на один месяц: добавьте `--start 2026-09 --end 2026-09`. Полные ответы сайта сохраняются в `data/raw/gibdd_raw/` и содержат сведения об участниках ДТП: их нельзя публиковать и коммитить.
