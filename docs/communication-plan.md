## 2. Правила эскалации

Менеджер проекта сообщает спонсору / куратору сразу, не дожидаясь планового статуса, если:
- сдвигается критический путь или возникает угроза срыва ключевой вехи / сдачи проекта;
- требуется использовать управленческий резерв либо перерасход бюджета / отклонение по трудозатратам грозит превысить лимит устава (не более 10%);
- заказчик или внешние обстоятельства требуют изменить границы MVP или содержание работ;
- выпадает участник команды или возникает критический блокер по данным / сервисам, который не удаётся снять силами команды;
- реализуется высокий риск или появляется новый риск с высоким влиянием, требующий решения куратора / заказчика.
