# Требования к продукту: Аналитика ДТП и опасных участков

## Пользователи и их задачи

| Пользователь | Что хочет сделать | Зачем |
|---|---|---|
| Аналитик дорожной безопасности | Найти опасные участки и понять причины ДТП | Подготовить отчёт для руководства и обосновать ремонт |
| Сотрудник ГИБДД | Увидеть участки концентрации ДТП | Понять, где нужно усилить контроль и посты |
| Руководитель дорожной службы | Получить приоритетный список участков | Распределить бюджет на ремонт дорог |

## Функциональные требования

| ID | Требование | Источник | Эпик | Приоритет (MoSCoW) |
|---|---|---|---|---|
| FR-01 | Система должна отображать на интерактивной карте опасные участки дорог | интервью, протокол от 16.10 | E3 | Must |
| FR-02 | Система должна позволять кликнуть на участок и увидеть статистику ДТП | интервью, протокол от 16.10 | E3 | Must |
| FR-03 | Система должна поддерживать фильтрацию данных на карте (погода, время) | интервью, протокол от 16.10 | E2 | Should |
| FR-04 | Система должна выгружать список опасных участков с приоритетами в CSV/Excel | интервью, протокол от 16.10 | E4 | Could |
| FR-05 | Система должна строить отчёты по участку или фактору риска | интервью, протокол от 16.10 | E4 | Should |

| ID | Категория | Требование (измеримо) | Как проверим |

## Требования к данным

| ID | Требование | Порог | Как проверим |
|---|---|---|---|
| DR-01 | Полнота | Не менее 90% записей о ДТП имеют точные координаты | Профилирование координат в датасете |
| DR-02 | Точность положения | Привязка ДТП к участку дороги с точностью до 50 метров | Проверка координат на тестовой выборке |
| DR-03 | Актуальность | Данные о ДТП за последние 3 года | Проверка поля `date` |
| DR-04 | Лицензия и указание авторства | На карте всегда видна подпись «© участники OpenStreetMap» и дата | Визуальная проверка |

## Карта историй и MVP

| | Найти данные (E1) | Оценить риск (E2) | Посмотреть на карте (E3) | Принять решение (E4) | Поделиться (E5) |
|---|---|---|---|---|---|
| **MVP** | US-1. Обновление данных (Should) | US-2. Карта опасных участков (Must) | US-3. Детальная статистика (Must) | | US-5. Доступ по ссылке (Must) |
| **Следующие версии** | | | | US-4. Выгрузка в Excel (Could) | |

**Обоснование границы MVP:** Первая версия продукта проверяет гипотезу: «Если показать дорожным службам опасные участки на карте с обоснованием, они смогут принимать решения по ремонту быстрее». Для этого нужен сквозной путь: открыть ссылку (US-5) → увидеть проблему (US-2) → кликнуть и понять причину (US-3). Выгрузка в Excel (US-4) отложена, так как без неё можно провести первое совещание.

## Вне рамок продукта

- Мобильное приложение.
- Интеграция с камерами в реальном времени.
- Автоматическая рассылка предписаний дорожным службам.
- Прогнозирование ДТП (перенесено в post-MVP).
