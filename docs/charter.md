# Устав проекта: Аналитика ДТП и опасных участков

Версия 1.2 · Дата: 11.11.2026 · Авторы: Рязанов, Ковальчук · Статус: на согласовании



## 1\. Проблема и ценность

У сотрудников дорожных служб и ГИБДД есть проблема: данные о ДТП накапливаются в разрозненных источниках (статистика ГИБДД, погодные сервисы, паспорта дорог), но единой картины опасных участков нет. Из-за этого очаги аварийности выявляют постфактум по числу погибших, а не по совокупности факторов риска. Сейчас это решают вручную: аналитики выгружают Excel-таблицы и строят сводки раз в квартал. Это не работает, потому что ручной анализ занимает недели, не учитывает связи между погодой, временем суток и состоянием дороги, и не позволяет оперативно перераспределять ресурсы на ремонт.

Подробнее: [business-case.md](business-case.md)

## 3\. Границы проекта

**Входит:**

* сбор и очистка данных о ДТП за 3 года;
* добавление данных о погоде и дорогах;
* выявление опасных участков;
* интерактивная карта с фильтрами;
* отчёты для ремонта;
* публикация на GitHub Pages.

**Не входит:**

* мобильное приложение;
* интеграция с камерами в реальном времени;
* автоматическая рассылка предписаний;
* интеграция с городскими системами;
* мониторинг состояния дорог.

## 4\. Допущения и ограничения

**Допущения:**
* открытых данных о ДТП достаточно для анализа (подтверждено в ЛР 2, но только для ДТП с пострадавшими);
* пространственная привязка достаточна для учебного проекта: 91,5% точек ДТП находятся в пределах 50 м от ближайшей дороги (Q4);
* заказчик не меняет требования после ЛР 3.

**Ограничения:**

* срок — до конца семестра;
* команда 2 человека, по 6 часов в неделю;
* для анализа используются категории погоды из карточек ГИБДД. Поле `weather` заполнено во всех 2975 карточках, поэтому загрузка Open-Meteo отложена. Количественные параметры погоды, включая температуру и видимость, недоступны (Q3);
* только бесплатные сервисы;
* нет доступа к закрытым базам ГИБДД.

## 10\. Предварительные критерии приёмки продукта

- Карта открывается по ссылке в браузере. На ней видны опасные участки дорог, а при выборе участка открывается его статистика ДТП (US-5, US-2, US-3).
- Карта поддерживает фильтры по категории погоды из карточек ГИБДД и по времени ДТП (FR-03).
- На готовых данных подготовка карты и сводки занимает не более одного рабочего дня. К концу семестра карта показывает не менее 50 участков.

Подробные требования и граница MVP приведены в [docs/requirements.md](requirements.md).
